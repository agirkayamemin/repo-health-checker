## [1.0.0] - 2026-08-10

### Added

- Read-only local Git repository validation and state collection.
- Documentation, test, CI, hygiene, and large tracked-file checks.
- Deterministic 0-100 scoring with PASS, WARN, FAIL, and SKIP results.
- Human-readable terminal and stable JSON reports.
- CLI `check` command with documented output formats and exit codes.
- Offline test suite and GitHub Actions configuration.
